Политика конфиденциальности

Студия «На связи» используется только её владельцем для публикации материалов в собственных каналах.

Какие данные используются

При подключении YouTube студия получает доступ к каналу владельца с правами youtube.upload и youtube.readonly. Доступ нужен только для загрузки видео, которые владелец сам одобрил, и для чтения статистики собственного канала.

Хранение и передача

Ключи доступа и данные канала хранятся на сервере владельца и не передаются третьим лицам, не продаются и не используются для рекламы. Данные других пользователей Google студия не получает.

Использование данных, полученных через Google API, соответствует Google API Services User Data Policy, включая требования Limited Use.

Отзыв доступа

Доступ можно отозвать в любой момент на странице настроек доступа аккаунта Google. После отзыва студия удаляет сохранённые ключи при следующем обращении.
